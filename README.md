

# CS 252 Tools

These tools are for the major portions of the CS252 course. They include:
- Number Representations
- Transitors
- Logic Gates
- Finite State Machines
- Microarchitecture
- Instruction Set Architecture



## Installation
for textbooksim

npm install
npm start


for risc-v-graphical-data-path-simulator
npm install
npm run serve


for fsm simulator
npm install
npm run build
