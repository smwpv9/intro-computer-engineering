

# CS 252 Tools

These tools are for the major portions of the CS252 course. They include:
- Number Representations
- Transitors
- Logic Gates
- Finite State Machines
- Microarchitecture
- Instruction Set Architecture



## Installation
### Within isa folder
npm install
npm run build

This produces an html folder in the main repository
